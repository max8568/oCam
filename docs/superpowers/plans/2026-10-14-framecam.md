# FrameCam Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 做出一個類似 oCam 的 Windows 螢幕錄影工具 FrameCam，主要差別是拖曳錄影框時有放大鏡，可以把框對到指定的像素。

**Architecture:** `FrameCam.Core` 放所有跟畫面無關的計算（框的位置、吸附、放大鏡、檔名、設定），全部有自動測試。`FrameCam` 是 WinForms 程式，負責視窗、滑鼠鍵盤、快捷鍵，錄影交給 ScreenRecorderLib，截圖用 GDI。所有座標都是螢幕實際的像素（Per-Monitor V2）。

**Tech Stack:** C#、.NET 10、WinForms、ScreenRecorderLib 7.0.1、xUnit、ffmpeg（只在測試時用）。

**Spec:** `docs/superpowers/specs/2026-10-14-framecam-design.md`（執行前兩份都要讀）

## Global Constraints

- 目標框架：`FrameCam.Core` 和 `FrameCam.Core.Tests` 用 `net10.0`；`FrameCam` 和 `FrameCam.CaptureTests` 用 `net10.0-windows`。
- `FrameCam` 和 `FrameCam.CaptureTests` 一律 `<PlatformTarget>x64</PlatformTarget>`。ScreenRecorderLib 用 `ExcludeAssets="build"` 加上直接引用 `$(PkgScreenRecorderLib)\build\x64\ScreenRecorderLib.dll`，不要改用套件自帶的 targets。
- ScreenRecorderLib 固定 7.0.1。除了 ScreenRecorderLib 和 xunit 範本自帶的套件，不加其他 NuGet 套件。
- 最低 Windows 10 2004（組建 19041），因為用到 `WDA_EXCLUDEFROMCAPTURE`。
- 程式宣告 `<ApplicationHighDpiMode>PerMonitorV2</ApplicationHighDpiMode>`；所有座標是實際像素；`PixelRect` 的 Right 和 Bottom 不含在範圍內（exclusive）。
- 錄影範圍永遠：在一個螢幕內、寬高是偶數、至少 32×32。
- `FrameWindow`、`MagnifierWindow`、`ControlBarForm` 都要設 `WDA_EXCLUDEFROMCAPTURE`。
- 錄影框和放大鏡用 `AutoScaleMode.None`，並在 `OnDpiChanged` 設 `e.Cancel = true`；控制列和設定視窗用 `AutoScaleMode.Dpi`。
- 預設值：錄影 F2、截圖 F3、每秒 60 格、存檔資料夾 `影片\FrameCam`、設定檔 `%APPDATA%\FrameCam\settings.json`、檔名 `yyyy-MM-dd_HH-mm-ss`，重複時加 `_2`、`_3`。
- 介面上的文字用繁體中文；程式碼的名稱和註解用英文。
- commit 作者已經在這個 repo 設成 `max8568`，不要改。push 前先跑 `gh auth status`，確認作用中的帳號是 max8568。

## Review Focus

使用者很可能碰到、但規格沒有明講的五種情況。每一項都已經在負責的任務裡加了測試：

1. **螢幕縮放不是 100%**：錄影框視窗的實際位置必須跟計算出來的一樣，不能被 WinForms 自動縮放改掉。→ Task 7 `FrameWindowPlacementTests` 在每一個螢幕上檢查。
2. **範圍貼齊螢幕右下角**：ScreenRecorderLib 截取範圍時，在螢幕邊緣最容易差一個像素。→ Task 1 `Region_touching_monitor_bottom_right_is_recorded_pixel_exact`。
3. **按下停止後、檔案還沒存完時又按一次快捷鍵**：應該什麼都不做，只產生一個檔案。→ Task 1 `Stopping_twice_finishes_once`（錄影元件），Task 11 的 `_stopping` 判斷（控制列）。
4. **存檔資料夾名稱有空白和中文字**：使用者很可能選這種資料夾。→ Task 1 的錄影測試全部存到 `framecam 測試 ...` 資料夾。
5. **settings.json 是別的版本寫的，或被手動改過**（有不認得的欄位、缺欄位、每秒格數不是 30 或 60）：要能讀，其他欄位用預設值。→ Task 6 `Unknown_fields_are_ignored_and_missing_or_invalid_ones_use_defaults`。

```csharp
namespace FrameCam.Core;

/// <summary>A point in physical screen pixels (virtual-desktop coordinates).</summary>
public readonly record struct PixelPoint(int X, int Y);

/// <summary>A size in physical pixels.</summary>
public readonly record struct PixelSize(int Width, int Height);

/// <summary>
/// A rectangle in physical screen pixels. Right and Bottom are exclusive: the rectangle
/// covers columns Left..Right-1 and rows Top..Bottom-1.
/// </summary>
public readonly record struct PixelRect(int Left, int Top, int Width, int Height)
{
    public int Right => Left + Width;
    public int Bottom => Top + Height;
    public PixelPoint Center => new(Left + Width / 2, Top + Height / 2);

    public static PixelRect FromEdges(int left, int top, int right, int bottom) =>
        new(left, top, right - left, bottom - top);

    public bool Contains(PixelPoint p) =>
        p.X >= Left && p.X < Right && p.Y >= Top && p.Y < Bottom;

    public bool Contains(PixelRect r) =>
        r.Left >= Left && r.Top >= Top && r.Right <= Right && r.Bottom <= Bottom;

    public bool IntersectsWith(PixelRect r) =>
        r.Left < Right && Left < r.Right && r.Top < Bottom && Top < r.Bottom;

    /// <summary>The overlapping part, or an empty rectangle (all zero) when they do not overlap.</summary>
    public PixelRect Intersect(PixelRect r)
    {
        int left = Math.Max(Left, r.Left), top = Math.Max(Top, r.Top);
        int right = Math.Min(Right, r.Right), bottom = Math.Min(Bottom, r.Bottom);
        return right > left && bottom > top ? FromEdges(left, top, right, bottom) : default;
    }

    public PixelRect Inflate(int amount) =>
        FromEdges(Left - amount, Top - amount, Right + amount, Bottom + amount);

    public PixelRect Offset(int dx, int dy) => new(Left + dx, Top + dy, Width, Height);
}

/// <summary>
/// A monitor: device name such as \\.\DISPLAY1, bounds in physical pixels,
/// and its scaling (1.0 = 100%, 1.5 = 150%).
/// </summary>
public sealed record MonitorInfo(string DeviceName, PixelRect Bounds, bool IsPrimary, double Scale);
```

```csharp
using System.Runtime.ExceptionServices;

namespace FrameCam.CaptureTests;

/// <summary>
/// Runs async test scenarios on a fresh STA thread with a WinForms message loop. The process is made
/// Per-Monitor V2 DPI aware first, like the app, so every coordinate is in physical pixels.
/// </summary>
internal static class Sta
{
    static Sta() => Application.SetHighDpiMode(HighDpiMode.PerMonitorV2);

    public static void Run(Func<Task> scenario) => Run(async () => { await scenario(); return true; });

    public static T Run<T>(Func<Task<T>> scenario)
    {
        T result = default!;
        ExceptionDispatchInfo? error = null;
        var thread = new Thread(() =>
        {
            var context = new WindowsFormsSynchronizationContext();
            SynchronizationContext.SetSynchronizationContext(context);
            context.Post(async _ =>
            {
                try { result = await scenario(); }
                catch (Exception e) { error = ExceptionDispatchInfo.Capture(e); }
                finally { Application.ExitThread(); }
            }, null);
            Application.Run();
        });
        thread.SetApartmentState(ApartmentState.STA);
        thread.Start();
        thread.Join();
        error?.Throw();
        return result;
    }
}
```

`tests/FrameCam.CaptureTests/Ffmpeg.cs`：

```csharp
using System.Diagnostics;
using System.Globalization;
using System.Text.RegularExpressions;

namespace FrameCam.CaptureTests;

/// <summary>Runs ffmpeg/ffprobe from PATH to inspect recorded files. Test-only; never shipped.</summary>
internal static class Ffmpeg
{
    public static bool IsAvailable => Find("ffmpeg") is not null && Find("ffprobe") is not null;

    public static (int Width, int Height) VideoSize(string path)
    {
        string text = RunText("ffprobe", $"-v error -select_streams v:0 -show_entries stream=width,height -of csv=p=0:s=x \"{path}\"").Trim();
        var parts = text.Split('x');
        return (int.Parse(parts[0], CultureInfo.InvariantCulture), int.Parse(parts[1], CultureInfo.InvariantCulture));
    }

    public static int CountFrames(string path) =>
        int.Parse(RunText("ffprobe", $"-v error -count_frames -select_streams v:0 -show_entries stream=nb_read_frames -of csv=p=0 \"{path}\"").Trim(),
            CultureInfo.InvariantCulture);

    /// <summary>Every video frame as 8-bit luma, row by row.</summary>
    public static (int Width, int Height, List<byte[]> Frames) DecodeLuma(string path)
    {
        var (width, height) = VideoSize(path);
        byte[] bytes = RunBinary("ffmpeg", $"-v error -i \"{path}\" -map 0:v:0 -f rawvideo -pix_fmt gray -");
        int frameSize = width * height;
        var frames = new List<byte[]>();
        for (int offset = 0; offset + frameSize <= bytes.Length; offset += frameSize)
            frames.Add(bytes.AsSpan(offset, frameSize).ToArray());
        return (width, height, frames);
    }

    public static bool HasAudioStream(string path) =>
        RunText("ffprobe", $"-v error -select_streams a -show_entries stream=codec_type -of csv=p=0 \"{path}\"").Contains("audio");

    /// <summary>Mean volume of the first audio track in dB. Digital silence is about -91 dB.</summary>
    public static double MeanVolumeDb(string path)
    {
        string log = RunText("ffmpeg", $"-hide_banner -i \"{path}\" -map 0:a:0 -af volumedetect -f null -", returnStdErr: true);
        var match = Regex.Match(log, @"mean_volume:\s*(-?[\d.]+) dB");
        if (!match.Success)
            throw new InvalidOperationException("volumedetect output not found:\n" + log);
        return double.Parse(match.Groups[1].Value, CultureInfo.InvariantCulture);
    }

    private static string? Find(string exe) =>
        (Environment.GetEnvironmentVariable("PATH") ?? "")
            .Split(Path.PathSeparator, StringSplitOptions.RemoveEmptyEntries)
            .Select(dir => Path.Combine(dir.Trim(), exe + ".exe"))
            .FirstOrDefault(File.Exists);

    private static byte[] RunBinary(string exe, string args)
    {
        using var process = Start(exe, args);
        var stderr = process.StandardError.ReadToEndAsync();
        using var output = new MemoryStream();
        process.StandardOutput.BaseStream.CopyTo(output);
        process.WaitForExit();
        if (process.ExitCode != 0)
            throw new InvalidOperationException($"{exe} {args} failed:\n{stderr.Result}");
        return output.ToArray();
    }

    private static string RunText(string exe, string args, bool returnStdErr = false)
    {
        using var process = Start(exe, args);
        var stdout = process.StandardOutput.ReadToEndAsync();
        var stderr = process.StandardError.ReadToEndAsync();
        process.WaitForExit();
        if (process.ExitCode != 0)
            throw new InvalidOperationException($"{exe} {args} failed:\n{stderr.Result}");
        return returnStdErr ? stderr.Result : stdout.Result;
    }

    private static Process Start(string exe, string args) =>
        Process.Start(new ProcessStartInfo(exe, args)
        {
            RedirectStandardOutput = true,
            RedirectStandardError = true,
            UseShellExecute = false,
            CreateNoWindow = true,
        }) ?? throw new InvalidOperationException($"could not start {exe}");
}
```

```csharp
namespace FrameCam.CaptureTests;

/// <summary>A [Fact] that is skipped when ffmpeg/ffprobe are not on PATH, or when it needs a second monitor that is missing.</summary>
public sealed class CaptureFactAttribute : FactAttribute
{
    private bool _needsSecondMonitor;

    public CaptureFactAttribute()
    {
        if (!Ffmpeg.IsAvailable)
            Skip = "ffmpeg/ffprobe not found on PATH";
    }

    public bool NeedsSecondMonitor
    {
```

```csharp
using System.Media;
using System.Text;

namespace FrameCam.CaptureTests;

/// <summary>Plays a looping sine tone through the default playback device until disposed.</summary>
internal sealed class Tone : IDisposable
{
    private readonly MemoryStream _wav;
    private readonly SoundPlayer _player;

    private Tone(MemoryStream wav)
    {
        _wav = wav;
        _player = new SoundPlayer(wav);
        _player.PlayLooping();
    }

    public static Tone Play(int frequency = 440) => new(CreateWav(frequency));

    public void Dispose()
    {
        _player.Stop();
        _player.Dispose();
        _wav.Dispose();
    }

    /// <summary>One second of 16-bit mono PCM; a whole number of cycles, so it loops without a click.</summary>
    private static MemoryStream CreateWav(int frequency)
    {
        const int sampleRate = 44100;
        const int samples = sampleRate;
        var stream = new MemoryStream();
        using (var w = new BinaryWriter(stream, Encoding.ASCII, leaveOpen: true))
        {
            w.Write("RIFF"u8);
            w.Write(36 + samples * 2);
            w.Write("WAVE"u8);
            w.Write("fmt "u8);
            w.Write(16);
            w.Write((short)1);              // PCM
            w.Write((short)1);              // mono
            w.Write(sampleRate);
            w.Write(sampleRate * 2);        // bytes per second
            w.Write((short)2);              // block align
            w.Write((short)16);             // bits per sample
            w.Write("data"u8);
            w.Write(samples * 2);
            for (int i = 0; i < samples; i++)
                w.Write((short)(Math.Sin(2 * Math.PI * frequency * i / sampleRate) * short.MaxValue * 0.5));
        }
        stream.Position = 0;
        return stream;
    }
}
```

```csharp
            yield return (x, height - 1);

            yield return (0, y);
            yield return (width - 1, y);
```

```csharp
using FrameCam.Core;
using ScreenRecorderLib;

namespace FrameCam.Recording;

/// <summary>IScreenRecorder backed by ScreenRecorderLib.</summary>
public sealed class ScreenRecorderLibRecorder : IScreenRecorder
{
    private Recorder? _recorder;
    private SynchronizationContext? _ui;

    public event EventHandler? Started;
    public event EventHandler<string>? Completed;
    public event EventHandler<string>? Failed;

    public bool IsRecording => _recorder is not null;

    public bool Start(RecordingRequest request)
    {
        if (_recorder is not null)
            throw new InvalidOperationException("Already recording.");
        _ui = SynchronizationContext.Current
            ?? throw new InvalidOperationException("Start must be called on a UI thread.");

        var loopback = Recorder.GetSystemAudioLoopbackDevices().FirstOrDefault(d => d.IsDefaultDevice);
        var recorder = Recorder.CreateRecorder(BuildOptions(request, loopback));
        recorder.OnStatusChanged += (_, e) =>
        {
            if (e.Status == RecorderStatus.Recording)
                Post(() => Started?.Invoke(this, EventArgs.Empty));
        };
        recorder.OnRecordingComplete += (_, e) => Post(() => Finish(recorder, () => Completed?.Invoke(this, e.FilePath)));
        recorder.OnRecordingFailed += (_, e) => Post(() => Finish(recorder, () => Failed?.Invoke(this, e.Error)));

        _recorder = recorder;
        try
        {
            recorder.Record(request.OutputPath);
        }
        catch
        {
            _recorder = null;
            recorder.Dispose();
            throw;
        }
        return loopback is not null;
    }

    public void Stop() => _recorder?.Stop();

    public void Dispose()
    {
        _recorder?.Dispose();
        _recorder = null;
    }

    private void Post(Action action) => _ui!.Post(_ => action(), null);

    /// <summary>Raises the ending event once per recording, after releasing the native recorder.</summary>
    private void Finish(Recorder recorder, Action raise)
    {
        if (!ReferenceEquals(_recorder, recorder))
            return;
        _recorder = null;
        recorder.Dispose();
        raise();
    }

    internal static RecorderOptions BuildOptions(RecordingRequest request, AudioSourceBase? audioSource)
    {
        var r = request.Region;
        var m = request.MonitorBounds;
        var source = new DisplayRecordingSource(request.MonitorDeviceName)
        {
            // Relative to the monitor's top-left (checked on a non-primary monitor by RecordingEngineTests).
            SourceRect = new ScreenRect(r.Left - m.Left, r.Top - m.Top, r.Width, r.Height),
            Stretch = StretchMode.None,
            IsCursorCaptureEnabled = true,
        };
        return new RecorderOptions
        {
            SourceOptions = new SourceOptions { RecordingSources = { source } },
            OutputOptions = new OutputOptions
            {
                RecorderMode = RecorderMode.Video,
                OutputFrameSize = new ScreenSize(r.Width, r.Height),
                Stretch = StretchMode.None,
            },
            VideoEncoderOptions = new VideoEncoderOptions
            {
                Framerate = request.FramesPerSecond,
                IsFixedFramerate = true,
                IsHardwareEncodingEnabled = true,
                IsFragmentedMp4Enabled = true,
                Encoder = new H264VideoEncoder
                {
                    BitrateMode = H264BitrateControlMode.Quality,
                    EncoderProfile = H264Profile.High,
                },
            },
            AudioOptions = new AudioOptions
            {
                IsAudioEnabled = audioSource is not null,
                Bitrate = AudioBitrate.bitrate_192kbps,
                Channels = AudioChannels.Stereo,
                AudioSources = audioSource is null ? [] : [audioSource],
            },
            MouseOptions = new MouseOptions { IsMousePointerEnabled = true },
        };
    }
}
```

```csharp
namespace FrameCam.Core;

/// <summary>
/// Window edges a dragged frame edge can snap to. X targets are left/right edges, Y targets are top/bottom
/// edges, in the same exclusive convention as PixelRect.Right and Bottom.
/// </summary>
public sealed class SnapTargets
{
    public const int Threshold = 8;
    public static readonly SnapTargets None = new([], []);

    private readonly int[] _xs;
    private readonly int[] _ys;

    public SnapTargets(IEnumerable<int> xs, IEnumerable<int> ys)
    {
        _xs = xs.Distinct().ToArray();
        _ys = ys.Distinct().ToArray();
    }

    /// <summary>The edges of every non-empty rectangle that overlaps the monitor.</summary>
    public static SnapTargets FromRects(IEnumerable<PixelRect> rects, PixelRect monitor)
    {
        var onMonitor = rects.Where(r => r.Width > 0 && r.Height > 0 && r.IntersectsWith(monitor)).ToList();
        return new SnapTargets(
            onMonitor.SelectMany(r => new[] { r.Left, r.Right }),
            onMonitor.SelectMany(r => new[] { r.Top, r.Bottom }));
    }

    public int SnapX(int x) => Snap(x, _xs);

    public int SnapY(int y) => Snap(y, _ys);

    /// <summary>The nearest target at most Threshold pixels away, or the value itself.</summary>
    private static int Snap(int value, int[] targets)
    {
        int best = value, bestDistance = Threshold + 1;
        foreach (int target in targets)
        {
            int distance = Math.Abs(target - value);
            if (distance < bestDistance)
            {
                best = target;
                bestDistance = distance;
            }
        }
        return best;
    }
}
```

`src/FrameCam.Core/FrameGeometry.cs`：

```csharp
namespace FrameCam.Core;

/// <summary>
/// Calculations for dragging the recording region (spec 7.1, 7.2). Every region returned is inside its
/// monitor, has an even width and height, and is at least MinSize on each side.
/// </summary>
public static class FrameGeometry
{
    public const int MinSize = 32;

    /// <summary>The largest even number not greater than value.</summary>
    public static int FloorEven(int value) => value - (value & 1);

    /// <summary>
    /// The region while an edge or corner is dragged. start is the region when the drag began and delta is
    /// the cursor movement since then. Each dragged edge snaps to a target within SnapTargets.Threshold,
    /// stays on the monitor, keeps at least MinSize from the opposite edge, and then moves toward the
    /// opposite edge as needed to make the size even.
    /// </summary>
    public static PixelRect Resize(PixelRect start, Handle handle, PixelPoint delta, PixelRect monitor, SnapTargets snap)
    {
        if (handle == Handle.Move)
            throw new ArgumentException("Use Move for Handle.Move.", nameof(handle));

        int left = start.Left, top = start.Top, right = start.Right, bottom = start.Bottom;
        if (handle.MovesLeft())
        {
            left = Math.Clamp(snap.SnapX(start.Left + delta.X), monitor.Left, right - MinSize);
            left = right - FloorEven(right - left);
        }
        else if (handle.MovesRight())
        {
            right = Math.Clamp(snap.SnapX(start.Right + delta.X), left + MinSize, monitor.Right);
            right = left + FloorEven(right - left);
        }
        if (handle.MovesTop())
        {
            top = Math.Clamp(snap.SnapY(start.Top + delta.Y), monitor.Top, bottom - MinSize);
            top = bottom - FloorEven(bottom - top);
        }
        else if (handle.MovesBottom())
        {
            bottom = Math.Clamp(snap.SnapY(start.Bottom + delta.Y), top + MinSize, monitor.Bottom);
            bottom = top + FloorEven(bottom - top);
        }
        return PixelRect.FromEdges(left, top, right, bottom);
    }

    /// <summary>
    /// The region while the whole frame is dragged. monitor is the monitor under the cursor; the start size
    /// is shrunk to fit it when needed, so dragging back to a bigger monitor restores the size.
    /// </summary>
    public static PixelRect Move(PixelRect start, PixelPoint delta, PixelRect monitor) =>
        ClampToMonitor(start.Offset(delta.X, delta.Y), monitor);

    /// <summary>Shrinks the region to fit the monitor (keeping the size even), then shifts it inside.</summary>
    public static PixelRect ClampToMonitor(PixelRect region, PixelRect monitor)
    {
        int width = Math.Max(MinSize, FloorEven(Math.Min(region.Width, monitor.Width)));
        int height = Math.Max(MinSize, FloorEven(Math.Min(region.Height, monitor.Height)));
        int left = Math.Clamp(region.Left, monitor.Left, monitor.Right - width);
        int top = Math.Clamp(region.Top, monitor.Top, monitor.Bottom - height);
        return new PixelRect(left, top, width, height);
    }
}
```

```csharp
namespace FrameCam.Core;

public enum Arrow
{
    Left,
    Up,
    Right,
    Down,
}

/// <summary>Keyboard nudges, size presets and fitting to a window (spec 7.4, 7.5).</summary>
public static class FrameAdjust
{
    public static readonly IReadOnlyList<PixelSize> Presets =
        [new(1920, 1080), new(1280, 720), new(854, 480), new(640, 360)];

    /// <summary>Arrow key: moves the whole region 1 pixel, staying on the monitor.</summary>
    public static PixelRect Nudge(PixelRect region, Arrow arrow, PixelRect monitor)
    {
        var (dx, dy) = Direction(arrow);
        return FrameGeometry.ClampToMonitor(region.Offset(dx, dy), monitor);
    }

    /// <summary>
    /// Ctrl+arrow: moves the active handle's edge 2 pixels in the arrow direction. A corner uses left/right
    /// for its vertical edge and up/down for its horizontal edge; a side ignores arrows across it. The region
    /// is returned unchanged when the move would leave the monitor or go below MinSize.
    /// </summary>
    public static PixelRect NudgeEdge(PixelRect region, Handle active, Arrow arrow, PixelRect monitor)
    {
        var (dx, dy) = Direction(arrow);
        int left = region.Left, top = region.Top, right = region.Right, bottom = region.Bottom;
        if (dx != 0)
        {
            if (active.MovesLeft()) left += 2 * dx;
            else if (active.MovesRight()) right += 2 * dx;
            else return region;
        }
        else
        {
            if (active.MovesTop()) top += 2 * dy;
            else if (active.MovesBottom()) bottom += 2 * dy;
            else return region;
        }
        var moved = PixelRect.FromEdges(left, top, right, bottom);
        bool valid = monitor.Contains(moved) && moved.Width >= FrameGeometry.MinSize && moved.Height >= FrameGeometry.MinSize;
        return valid ? moved : region;
    }

    /// <summary>The preset size with the top-left kept, moved up/left just enough to fit. Null when larger than the monitor.</summary>
    public static PixelRect? ApplyPreset(PixelRect region, PixelSize size, PixelRect monitor)
    {
        if (size.Width > monitor.Width || size.Height > monitor.Height)
            return null;
        return FrameGeometry.ClampToMonitor(new PixelRect(region.Left, region.Top, size.Width, size.Height), monitor);
    }

    public static PixelRect FullMonitor(PixelRect monitor) =>
        new(monitor.Left, monitor.Top, FrameGeometry.FloorEven(monitor.Width), FrameGeometry.FloorEven(monitor.Height));

    /// <summary>
    /// The region for a window's outer bounds or client area: the part on the monitor, with the right and
    /// bottom edges moved in by 1 pixel when the size is odd. Null when that is smaller than MinSize.
    /// </summary>
    public static PixelRect? FitToWindow(PixelRect window, PixelRect monitor)
    {
        var visible = window.Intersect(monitor);
        var fitted = new PixelRect(visible.Left, visible.Top, FrameGeometry.FloorEven(visible.Width), FrameGeometry.FloorEven(visible.Height));
        return fitted.Width >= FrameGeometry.MinSize && fitted.Height >= FrameGeometry.MinSize ? fitted : null;
    }

    private static (int Dx, int Dy) Direction(Arrow arrow) => arrow switch
    {
        Arrow.Left => (-1, 0),
        Arrow.Right => (1, 0),
        Arrow.Up => (0, -1),
        Arrow.Down => (0, 1),
        _ => throw new ArgumentOutOfRangeException(nameof(arrow)),
    };
}
```

```csharp
namespace FrameCam.Core;

/// <summary>
/// Where the frame window's parts go for a region, in screen pixels (spec 7.1): a 4-pixel border ring just
/// outside the region, 9×9 handles outside its corners and edge midpoints, and the size label above the
/// top-left corner, or inside the region's top-left when there is no room above on the monitor.
/// </summary>
public sealed class FrameLayout
{
    public const int BorderWidth = 4;
    public const int HandleSize = 9;
    public const int CornerReach = 16;

    public FrameLayout(PixelRect region, PixelSize labelSize, PixelRect monitor)
    {
        Region = region;

        int labelTop = region.Top - BorderWidth - labelSize.Height;
        Label = labelTop >= monitor.Top
            ? new PixelRect(Math.Max(region.Left - BorderWidth, monitor.Left), labelTop, labelSize.Width, labelSize.Height)
            : new PixelRect(region.Left, region.Top, labelSize.Width, labelSize.Height);

        var outer = region.Inflate(BorderWidth);
        Ring =
        [
            PixelRect.FromEdges(outer.Left, outer.Top, outer.Right, region.Top),
            PixelRect.FromEdges(outer.Left, region.Bottom, outer.Right, outer.Bottom),
            PixelRect.FromEdges(outer.Left, region.Top, region.Left, region.Bottom),
            PixelRect.FromEdges(region.Right, region.Top, outer.Right, region.Bottom),
        ];

        const int h = HandleSize;
        int midX = region.Left + region.Width / 2 - h / 2;
        int midY = region.Top + region.Height / 2 - h / 2;
        Handles =
        [
            (Handle.TopLeft, new PixelRect(region.Left - h, region.Top - h, h, h)),
            (Handle.Top, new PixelRect(midX, region.Top - h, h, h)),
            (Handle.TopRight, new PixelRect(region.Right, region.Top - h, h, h)),
            (Handle.Right, new PixelRect(region.Right, midY, h, h)),
            (Handle.BottomRight, new PixelRect(region.Right, region.Bottom, h, h)),
            (Handle.Bottom, new PixelRect(midX, region.Bottom, h, h)),
            (Handle.BottomLeft, new PixelRect(region.Left - h, region.Bottom, h, h)),
            (Handle.Left, new PixelRect(region.Left - h, midY, h, h)),
        ];

        var aroundHandles = region.Inflate(HandleSize);
        WindowBounds = PixelRect.FromEdges(
            Math.Min(aroundHandles.Left, Label.Left),
            Math.Min(aroundHandles.Top, Label.Top),
            Math.Max(aroundHandles.Right, Label.Right),
            Math.Max(aroundHandles.Bottom, Label.Bottom));
    }

    public PixelRect Region { get; }
    public PixelRect Label { get; }
    public IReadOnlyList<PixelRect> Ring { get; }
    public IReadOnlyList<(Handle Handle, PixelRect Rect)> Handles { get; }
    public PixelRect WindowBounds { get; }

    /// <summary>What a press at this screen point grabs, or null when the point is not on the frame.</summary>
    public Handle? HitTest(PixelPoint p)
    {
        if (Label.Contains(p))
            return Handle.Move;
        if (!Ring.Any(r => r.Contains(p)) && !Handles.Any(h => h.Rect.Contains(p)))
            return null;

        var r = Region;
        bool left = p.X < r.Left, right = p.X >= r.Right, top = p.Y < r.Top, bottom = p.Y >= r.Bottom;
        // On a side, the part within CornerReach of a corner grabs that corner.
        if ((left || right) && !(top || bottom))
        {
            top = p.Y < Math.Min(r.Top + CornerReach, r.Center.Y);
            bottom = !top && p.Y >= Math.Max(r.Bottom - CornerReach, r.Center.Y);
        }
        else if ((top || bottom) && !(left || right))
        {
            left = p.X < Math.Min(r.Left + CornerReach, r.Center.X);
            right = !left && p.X >= Math.Max(r.Right - CornerReach, r.Center.X);
        }
        return (left, right, top, bottom) switch
        {
            (true, _, true, _) => Handle.TopLeft,
            (_, true, true, _) => Handle.TopRight,
            (true, _, _, true) => Handle.BottomLeft,
            (_, true, _, true) => Handle.BottomRight,
            (true, _, _, _) => Handle.Left,
            (_, true, _, _) => Handle.Right,
            (_, _, true, _) => Handle.Top,
            _ => Handle.Bottom,
        };
    }
}
```

```csharp
namespace FrameCam.Core;

/// <summary>
/// A region edge inside the magnifier, in source pixels from the view's top-left. A vertical line at
/// Offset k lies on the seam between source columns k-1 and k and spans rows From..To (To exclusive).
/// </summary>
public readonly record struct MagnifierLine(bool Vertical, int Offset, int From, int To);

/// <summary>Calculations for the magnifier (spec 7.3).</summary>
public static class MagnifierMath
{
    public const int SourcePixels = 21;
    public const int BaseZoom = 8;
    public const int CursorOffset = 24;

    /// <summary>
    /// The pixel to center on: just inside the grabbed corner, the point on the grabbed edge nearest the
    /// cursor, or the top-left pixel when the whole frame moves.
    /// </summary>
    public static PixelPoint FocusPoint(PixelRect region, Handle handle, PixelPoint cursor)
    {
        int x = Math.Clamp(cursor.X, region.Left, region.Right - 1);
        int y = Math.Clamp(cursor.Y, region.Top, region.Bottom - 1);
        return handle switch
        {
            Handle.Move or Handle.TopLeft => new(region.Left, region.Top),
            Handle.TopRight => new(region.Right - 1, region.Top),
            Handle.BottomLeft => new(region.Left, region.Bottom - 1),
            Handle.BottomRight => new(region.Right - 1, region.Bottom - 1),
            Handle.Left => new(region.Left, y),
            Handle.Right => new(region.Right - 1, y),
            Handle.Top => new(x, region.Top),
            Handle.Bottom => new(x, region.Bottom - 1),
            _ => throw new ArgumentOutOfRangeException(nameof(handle)),
        };
    }

    /// <summary>The screen pixels shown, centered on the focus pixel.</summary>
    public static PixelRect SourceRect(PixelPoint focus) =>
        new(focus.X - SourcePixels / 2, focus.Y - SourcePixels / 2, SourcePixels, SourcePixels);

    /// <summary>Screen pixels per source pixel: 8 at 100% scaling, 12 at 150%.</summary>
    public static int Zoom(double monitorScale) => Math.Max(1, (int)Math.Round(BaseZoom * monitorScale));

    /// <summary>The region's edges that cross the view, clipped to the view.</summary>
    public static IReadOnlyList<MagnifierLine> BoundaryLines(PixelRect source, PixelRect region)
    {
        var lines = new List<MagnifierLine>();
        int rowFrom = Math.Clamp(region.Top - source.Top, 0, source.Height);
        int rowTo = Math.Clamp(region.Bottom - source.Top, 0, source.Height);
        int colFrom = Math.Clamp(region.Left - source.Left, 0, source.Width);
        int colTo = Math.Clamp(region.Right - source.Left, 0, source.Width);
        if (rowFrom < rowTo)
        {
            AddIfInView(lines, true, region.Left - source.Left, rowFrom, rowTo, source.Width);
            AddIfInView(lines, true, region.Right - source.Left, rowFrom, rowTo, source.Width);
        }
        if (colFrom < colTo)
        {
            AddIfInView(lines, false, region.Top - source.Top, colFrom, colTo, source.Height);
            AddIfInView(lines, false, region.Bottom - source.Top, colFrom, colTo, source.Height);
        }
        return lines;
    }

    /// <summary>
    /// Top-left of the magnifier window: CursorOffset below and right of the anchor, flipped to the other
    /// side where it would leave the monitor.
    /// </summary>
    public static PixelPoint Placement(PixelPoint anchor, PixelSize size, PixelRect monitor)
    {
        int x = anchor.X + CursorOffset;
        if (x + size.Width > monitor.Right)
            x = anchor.X - CursorOffset - size.Width;
        int y = anchor.Y + CursorOffset;
        if (y + size.Height > monitor.Bottom)
            y = anchor.Y - CursorOffset - size.Height;
        return new PixelPoint(
            Math.Clamp(x, monitor.Left, Math.Max(monitor.Left, monitor.Right - size.Width)),
            Math.Clamp(y, monitor.Top, Math.Max(monitor.Top, monitor.Bottom - size.Height)));
    }

    private static void AddIfInView(List<MagnifierLine> lines, bool vertical, int offset, int from, int to, int extent)
    {
        if (offset >= 0 && offset <= extent)
            lines.Add(new MagnifierLine(vertical, offset, from, to));
    }
}
```

```csharp
{
    private static readonly JsonSerializerOptions Json = new()
    {
        WriteIndented = true,
        Encoder = JavaScriptEncoder.UnsafeRelaxedJsonEscaping, // keep CJK folder names readable
    };

    public static string DefaultPath =>
        Path.Combine(Environment.GetFolderPath(Environment.SpecialFolder.ApplicationData), "FrameCam", "settings.json");

    /// <summary>
    /// Reads the settings. A missing file gives defaults and no error; an unreadable or invalid file gives
    /// defaults and a message for the user. Unknown fields are ignored; missing or invalid ones get defaults.

    {
        if (!File.Exists(path))

        try

                ?? throw new JsonException("settings.json is null");

    }

            RecordHotkey = string.IsNullOrWhiteSpace(s.RecordHotkey) ? defaults.RecordHotkey : s.RecordHotkey,
            ScreenshotHotkey = string.IsNullOrWhiteSpace(s.ScreenshotHotkey) ? defaults.ScreenshotHotkey : s.ScreenshotHotkey,
```

```csharp
namespace FrameCam.Core;

public static class RegionPlacement
{
    public static readonly PixelSize DefaultSize = new(1280, 720);

    /// <summary>
    /// Where the region goes at startup or after the monitors change (spec 8.5): the saved region if its
    /// monitor still exists and it still fits there; otherwise the saved size, or 1280×720 on first run,
    /// centered on the primary monitor and shrunk to fit.
    /// </summary>
    public static (PixelRect Region, MonitorInfo Monitor) Restore(SavedRegion? saved, IReadOnlyList<MonitorInfo> monitors)
    {
        var primary = monitors.FirstOrDefault(m => m.IsPrimary) ?? monitors[0];
        if (saved is not null)
        {
            var monitor = monitors.FirstOrDefault(m => m.DeviceName == saved.DeviceName);
            if (monitor is not null && monitor.Bounds.Contains(saved.Rect))
                return (FrameGeometry.ClampToMonitor(saved.Rect, monitor.Bounds), monitor);
        }

        var size = saved is null ? DefaultSize : new PixelSize(saved.Width, saved.Height);
        var b = primary.Bounds;
```

```csharp
using FrameCam.Core;
using FrameCam.Native;

namespace FrameCam;

/// <summary>Monitors in physical pixels (the process is Per-Monitor V2 DPI aware) with their scaling.</summary>
internal static class Screens
{
    public static IReadOnlyList<MonitorInfo> All() => Screen.AllScreens.Select(ToMonitorInfo).ToList();

    public static MonitorInfo At(PixelPoint p) => ToMonitorInfo(Screen.FromPoint(new Point(p.X, p.Y)));

    private static MonitorInfo ToMonitorInfo(Screen screen) =>
        new(screen.DeviceName, screen.Bounds.ToPixelRect(), screen.Primary, ScaleOf(screen));

    private static double ScaleOf(Screen screen)
    {
        var center = new NativeMethods.POINT(screen.Bounds.X + screen.Bounds.Width / 2, screen.Bounds.Y + screen.Bounds.Height / 2);
        var monitor = NativeMethods.MonitorFromPoint(center, NativeMethods.MONITOR_DEFAULTTONEAREST);
        return NativeMethods.GetDpiForMonitor(monitor, NativeMethods.MDT_EFFECTIVE_DPI, out uint dpiX, out _) == 0
            ? dpiX / 96.0
            : 1.0;
    }
}
```

```csharp
using FrameCam.Core;
using FrameCam.Native;

namespace FrameCam.UI;

internal sealed class AdjustingEventArgs(PixelPoint focus, PixelPoint anchor) : EventArgs
{
    /// <summary>The screen pixel the magnifier centers on.</summary>
    public PixelPoint Focus { get; } = focus;

    /// <summary>The point the magnifier sits next to: the cursor, or the focus for keyboard nudges.</summary>
    public PixelPoint Anchor { get; } = anchor;
}

/// <summary>
/// The recording frame on screen (spec 7.1). The window's shape is only the border ring, the 8 handles and
/// the size label, all outside the region, so the region's pixels stay visible and clickable. The window is
/// left out of every screen capture.
/// </summary>
internal sealed class FrameWindow : Form
{
    private static readonly Color IdleColor = Color.FromArgb(0, 120, 215);
    private static readonly Color RecordingColor = Color.FromArgb(220, 40, 40);
    private static readonly Font LabelFont = new("Segoe UI", 12f, FontStyle.Bold, GraphicsUnit.Pixel);

    private PixelRect _region;
    private MonitorInfo _monitor;
    private FrameLayout _layout;
    private bool _locked;

    private Handle? _dragHandle;
    private PixelPoint _dragStartCursor;
    private PixelRect _dragStartRegion;
    private SnapTargets _dragSnap = SnapTargets.None;

    public FrameWindow(PixelRect region, MonitorInfo monitor)
    {
        FormBorderStyle = FormBorderStyle.None;
        ShowInTaskbar = false;
        TopMost = true;
        StartPosition = FormStartPosition.Manual;
        AutoScaleMode = AutoScaleMode.None;
        DoubleBuffered = true;
        BackColor = IdleColor;
        _region = region;
        _monitor = monitor;
        _layout = CreateLayout();
        ApplyLayout();
    }

    /// <summary>Raised on every drag step and keyboard nudge.</summary>
    public event EventHandler<AdjustingEventArgs>? Adjusting;

    /// <summary>Raised when a drag ends, and right after each keyboard nudge.</summary>
    public event EventHandler? AdjustEnded;

    /// <summary>Raised when Windows reports a DPI change for this window: scaling changed, or it moved to a monitor with another scale.</summary>
    public event EventHandler? ScaleChanged;

    public PixelRect CaptureRegion => _region;

    public MonitorInfo Monitor => _monitor;

    internal FrameLayout Layout => _layout;

    /// <summary>The edge or corner Ctrl+arrow moves: the last one dragged, bottom-right until then.</summary>
    public Handle ActiveHandle { get; private set; } = Handle.BottomRight;

    /// <summary>Gives the snap targets on a monitor when an edge drag starts; null means no snapping.</summary>
    public Func<PixelRect, SnapTargets>? SnapSource { get; set; }

    /// <summary>While locked (recording) the frame is red and ignores the mouse and keyboard.</summary>
    public bool Locked
    {
        get => _locked;
        set
        {
            _locked = value;
            _dragHandle = null;
            Capture = false;
            BackColor = value ? RecordingColor : IdleColor;
            Cursor = Cursors.Default;
            Invalidate();
        }
    }

    public void SetRegion(PixelRect region, MonitorInfo monitor)
    {
        if (region == _region && monitor == _monitor)
            return;
        _region = region;
        _monitor = monitor;
        _layout = CreateLayout();
        ApplyLayout();
    }

    /// <summary>Arrow moves the frame 1 pixel; Ctrl+arrow moves the active edge or corner 2 pixels. Returns true when handled.</summary>
    public bool TryHandleArrow(Keys keyData)
    {
        Arrow? arrow = (keyData & Keys.KeyCode) switch
        {
            Keys.Left => Arrow.Left,
            Keys.Right => Arrow.Right,
            Keys.Up => Arrow.Up,
            Keys.Down => Arrow.Down,
            _ => null,
        };
        var modifiers = keyData & Keys.Modifiers;
        if (arrow is null || _locked || (modifiers != Keys.None && modifiers != Keys.Control))
            return false;

        var handle = modifiers == Keys.Control ? ActiveHandle : Handle.Move;
        var region = handle == Handle.Move
            ? FrameAdjust.Nudge(_region, arrow.Value, _monitor.Bounds)
            : FrameAdjust.NudgeEdge(_region, handle, arrow.Value, _monitor.Bounds);
        SetRegion(region, _monitor);
        var focus = MagnifierMath.FocusPoint(_region, handle, _region.Center);
        Adjusting?.Invoke(this, new AdjustingEventArgs(focus, focus));
        AdjustEnded?.Invoke(this, EventArgs.Empty);
        return true;
    }

    protected override bool ShowWithoutActivation => true;

    protected override CreateParams CreateParams
    {
        get
        {
            var cp = base.CreateParams;
            cp.ExStyle |= NativeMethods.WS_EX_TOOLWINDOW;
            return cp;
        }
    }

    protected override void OnHandleCreated(EventArgs e)
    {
        base.OnHandleCreated(e);
        CaptureExclusion.Apply(Handle);
    }

    protected override void OnDpiChanged(DpiChangedEventArgs e)
    {
        e.Cancel = true; // keep the exact physical-pixel bounds set by ApplyLayout
        ScaleChanged?.Invoke(this, EventArgs.Empty);
    }

    protected override bool ProcessCmdKey(ref Message msg, Keys keyData) =>
        TryHandleArrow(keyData) || base.ProcessCmdKey(ref msg, keyData);

    protected override void OnMouseDown(MouseEventArgs e)
    {
        base.OnMouseDown(e);
        if (_locked || e.Button != MouseButtons.Left)
            return;
        var cursor = MousePosition.ToPixelPoint();
        if (_layout.HitTest(cursor) is not { } handle)
            return;
        _dragHandle = handle;
        _dragStartCursor = cursor;
        _dragStartRegion = _region;
        _dragSnap = handle == Handle.Move ? SnapTargets.None : SnapSource?.Invoke(_monitor.Bounds) ?? SnapTargets.None;
        if (handle != Handle.Move)
            ActiveHandle = handle;
        Adjusting?.Invoke(this, new AdjustingEventArgs(MagnifierMath.FocusPoint(_region, handle, cursor), cursor));
    }

    protected override void OnMouseMove(MouseEventArgs e)
    {
        base.OnMouseMove(e);
        var cursor = MousePosition.ToPixelPoint();
        if (_dragHandle is not { } handle)
        {
            Cursor = _locked ? Cursors.Default : CursorFor(_layout.HitTest(cursor));
            return;
        }
        var delta = new PixelPoint(cursor.X - _dragStartCursor.X, cursor.Y - _dragStartCursor.Y);
        if (handle == Handle.Move)
        {
            var monitor = Screens.At(cursor);
            SetRegion(FrameGeometry.Move(_dragStartRegion, delta, monitor.Bounds), monitor);
        }
        else
        {
            var snap = (ModifierKeys & Keys.Alt) != 0 ? SnapTargets.None : _dragSnap;
            SetRegion(FrameGeometry.Resize(_dragStartRegion, handle, delta, _monitor.Bounds, snap), _monitor);
        }
        Adjusting?.Invoke(this, new AdjustingEventArgs(MagnifierMath.FocusPoint(_region, handle, cursor), cursor));
    }

    protected override void OnMouseUp(MouseEventArgs e)
    {
        base.OnMouseUp(e);
        if (_dragHandle is null)
            return;
        _dragHandle = null;
        AdjustEnded?.Invoke(this, EventArgs.Empty);
    }

    protected override void OnPaint(PaintEventArgs e)
    {
        var g = e.Graphics;
        var color = _locked ? RecordingColor : IdleColor;
        using var border = new SolidBrush(color);
        using var outline = new Pen(color);
        foreach (var r in _layout.Ring)
            g.FillRectangle(border, ToClient(r));
        foreach (var (_, r) in _layout.Handles)
        {
            var c = ToClient(r);
            g.FillRectangle(_locked ? border : Brushes.White, c);
            g.DrawRectangle(outline, c.X, c.Y, c.Width - 1, c.Height - 1);
        }
        var label = ToClient(_layout.Label);
        g.FillRectangle(border, label);
        TextRenderer.DrawText(g, LabelText, LabelFont, label, Color.White,
            TextFormatFlags.HorizontalCenter | TextFormatFlags.VerticalCenter | TextFormatFlags.NoPadding);
    }

    private string LabelText => $"{_region.Width} × {_region.Height}";

    private FrameLayout CreateLayout()
    {
        var text = TextRenderer.MeasureText(LabelText, LabelFont, Size.Empty, TextFormatFlags.NoPadding);
        return new FrameLayout(_region, new PixelSize(text.Width + 12, text.Height + 6), _monitor.Bounds);
    }

    private void ApplyLayout()
    {
        Bounds = _layout.WindowBounds.ToRectangle();
        var shape = new Region(Rectangle.Empty);
        foreach (var r in _layout.Ring)
            shape.Union(ToClient(r));
        foreach (var (_, r) in _layout.Handles)
            shape.Union(ToClient(r));
        shape.Union(ToClient(_layout.Label));
        var old = Region;
        Region = shape;
        old?.Dispose();
        Invalidate();
    }

    private Rectangle ToClient(PixelRect r) =>
        new(r.Left - _layout.WindowBounds.Left, r.Top - _layout.WindowBounds.Top, r.Width, r.Height);

    private static Cursor CursorFor(Handle? handle) => handle switch
    {
        Handle.Left or Handle.Right => Cursors.SizeWE,
        Handle.Top or Handle.Bottom => Cursors.SizeNS,
        Handle.TopLeft or Handle.BottomRight => Cursors.SizeNWSE,
        Handle.TopRight or Handle.BottomLeft => Cursors.SizeNESW,
        Handle.Move => Cursors.SizeAll,
        _ => Cursors.Default,
    };
}
```

```csharp
using System.ComponentModel;
using System.Drawing.Drawing2D;
using System.Drawing.Imaging;
using FrameCam.Core;
using FrameCam.Native;

namespace FrameCam.UI;

/// <summary>
/// The magnifier (spec 7.3): the screen pixels around the focus point, enlarged, with pixels outside the
/// region dimmed and the region's edges drawn on the pixel seams. It never takes focus, lets clicks through,
/// and is left out of screen captures, so the pixels it copies never include itself or the frame.
/// </summary>
internal sealed class MagnifierWindow : Form
{
    private const int InfoHeight = 40; // at 100% scaling
    private const int HideDelayMs = 1500;

    private readonly FrameWindow _frame;
    private readonly System.Windows.Forms.Timer _hideTimer = new() { Interval = HideDelayMs };
    private readonly Bitmap _pixels = new(MagnifierMath.SourcePixels, MagnifierMath.SourcePixels, PixelFormat.Format24bppRgb);
    private PixelRect _source;
    private int _zoom = MagnifierMath.BaseZoom;
    private double _scale;
    private Font _font = new("Segoe UI", 12f, FontStyle.Bold, GraphicsUnit.Pixel);

    public MagnifierWindow(FrameWindow frame)
    {
        _frame = frame;
        FormBorderStyle = FormBorderStyle.None;
        ShowInTaskbar = false;
        TopMost = true;
        StartPosition = FormStartPosition.Manual;
        AutoScaleMode = AutoScaleMode.None;
        DoubleBuffered = true;
        BackColor = Color.Black;
        _hideTimer.Tick += (_, _) =>
        {
            _hideTimer.Stop();
            Hide();
        };
        frame.Adjusting += (_, e) => ShowFor(e);
        frame.AdjustEnded += (_, _) =>
        {
            _hideTimer.Stop();
            _hideTimer.Start();
        };
    }

    protected override bool ShowWithoutActivation => true;

    protected override CreateParams CreateParams
    {
        get
        {
            var cp = base.CreateParams;
            cp.ExStyle |= ClickThrough.ExStyle;
            return cp;
        }
    }

    protected override void OnHandleCreated(EventArgs e)
    {
        base.OnHandleCreated(e);
        ClickThrough.MakeOpaque(Handle);
        CaptureExclusion.Apply(Handle);
    }

    protected override void OnDpiChanged(DpiChangedEventArgs e) => e.Cancel = true;

    private void ShowFor(AdjustingEventArgs e)
    {
        _hideTimer.Stop();
        var monitor = Screens.At(e.Focus);
        if (monitor.Scale != _scale)
        {
            _scale = monitor.Scale;
            _zoom = MagnifierMath.Zoom(_scale);
            _font.Dispose();
            _font = new Font("Segoe UI", (float)(12 * _scale), FontStyle.Bold, GraphicsUnit.Pixel);
        }
        _source = MagnifierMath.SourceRect(e.Focus);
        CopyPixels();
        int side = MagnifierMath.SourcePixels * _zoom;
        var size = new PixelSize(side, side + (int)Math.Round(InfoHeight * _scale));
        var topLeft = MagnifierMath.Placement(e.Anchor, size, monitor.Bounds);
        Bounds = new Rectangle(topLeft.X, topLeft.Y, size.Width, size.Height);
        if (!Visible)
            Show();
        Invalidate();
    }

    private void CopyPixels()
    {
        using var g = Graphics.FromImage(_pixels);
        g.Clear(Color.Black);
        try
        {
            g.CopyFromScreen(_source.Left, _source.Top, 0, 0, new Size(_source.Width, _source.Height),
                CopyPixelOperation.SourceCopy | CopyPixelOperation.CaptureBlt);
        }
        catch (Win32Exception)
        {
            // Part of the view is off every monitor; it stays black.
        }
    }

    protected override void OnPaint(PaintEventArgs e)
    {
        var g = e.Graphics;
        var region = _frame.CaptureRegion;
        int n = MagnifierMath.SourcePixels, z = _zoom, side = n * z;

        g.InterpolationMode = InterpolationMode.NearestNeighbor;
        g.PixelOffsetMode = PixelOffsetMode.Half;
        g.DrawImage(_pixels, new Rectangle(0, 0, side, side));
        g.PixelOffsetMode = PixelOffsetMode.Default;

        using var dim = new SolidBrush(Color.FromArgb(150, 0, 0, 0));
        for (int y = 0; y < n; y++)
            for (int x = 0; x < n; x++)
                if (!region.Contains(new PixelPoint(_source.Left + x, _source.Top + y)))
                    g.FillRectangle(dim, x * z, y * z, z, z);

        using var grid = new Pen(Color.FromArgb(50, 255, 255, 255));
        for (int k = 1; k < n; k++)
        {
            g.DrawLine(grid, k * z, 0, k * z, side);
            g.DrawLine(grid, 0, k * z, side, k * z);
        }

        using var edge = new Pen(Color.FromArgb(0, 200, 255), Math.Max(2, z / 4));
        foreach (var line in MagnifierMath.BoundaryLines(_source, region))
        {
            if (line.Vertical)
                g.DrawLine(edge, line.Offset * z, line.From * z, line.Offset * z, line.To * z);
            else
                g.DrawLine(edge, line.From * z, line.Offset * z, line.To * z, line.Offset * z);
        }

        int infoHeight = Height - side;
        const TextFormatFlags center = TextFormatFlags.HorizontalCenter | TextFormatFlags.VerticalCenter;
        TextRenderer.DrawText(g, $"{region.Width} × {region.Height}", _font,
            new Rectangle(0, side, Width, infoHeight / 2), Color.White, center);
        TextRenderer.DrawText(g, $"({region.Left}, {region.Top})", _font,
            new Rectangle(0, side + infoHeight / 2, Width, infoHeight - infoHeight / 2), Color.White, center);
    }

    protected override void Dispose(bool disposing)
    {
        if (disposing)
        {
            _hideTimer.Dispose();
            _pixels.Dispose();
            _font.Dispose();
        }
        base.Dispose(disposing);
    }
}
```

```csharp
using System.Runtime.InteropServices;
using FrameCam.Core;

namespace FrameCam.Native;

/// <summary>A top-level window's outer bounds (without the invisible shadow border) and client area, in physical pixels.</summary>
internal sealed record WindowInfo(IntPtr Handle, PixelRect Outer, PixelRect Client);

internal static class WindowEnumerator
{
    /// <summary>Visible, non-minimized, non-cloaked top-level windows of other processes, topmost first.</summary>
    public static List<WindowInfo> VisibleWindows()
    {
        var result = new List<WindowInfo>();
        uint ownProcess = (uint)Environment.ProcessId;
        NativeMethods.EnumWindows((hwnd, _) =>
        {
            if (TryDescribe(hwnd, ownProcess) is { } window)
                result.Add(window);
            return true;
        }, IntPtr.Zero);
        return result;
    }

    /// <summary>Outer and client edges of the visible windows on the monitor (spec 7.5).</summary>
    public static SnapTargets SnapTargetsFor(PixelRect monitor) =>
        SnapTargets.FromRects(VisibleWindows().SelectMany(w => new[] { w.Outer, w.Client }), monitor);

    private static WindowInfo? TryDescribe(IntPtr hwnd, uint ownProcess)
    {
        if (!NativeMethods.IsWindowVisible(hwnd) || NativeMethods.IsIconic(hwnd))
            return null;
        NativeMethods.GetWindowThreadProcessId(hwnd, out uint process);
        if (process == ownProcess)
            return null;
        if (NativeMethods.DwmGetWindowAttribute(hwnd, NativeMethods.DWMWA_CLOAKED, out int cloaked, sizeof(int)) == 0 && cloaked != 0)
            return null;
        if (NativeMethods.DwmGetWindowAttribute(hwnd, NativeMethods.DWMWA_EXTENDED_FRAME_BOUNDS, out NativeMethods.RECT outer, Marshal.SizeOf<NativeMethods.RECT>()) != 0)
            return null;
        if (!NativeMethods.GetClientRect(hwnd, out var client))
            return null;
        var origin = new NativeMethods.POINT(0, 0);
        NativeMethods.ClientToScreen(hwnd, ref origin);

        var outerRect = PixelRect.FromEdges(outer.Left, outer.Top, outer.Right, outer.Bottom);
        if (outerRect.Width <= 0 || outerRect.Height <= 0)
            return null;
        return new WindowInfo(hwnd, outerRect, new PixelRect(origin.X, origin.Y, client.Right, client.Bottom));
    }
}
```

```csharp
namespace FrameCam.UI;

/// <summary>Converts hotkeys between Keys and the text in settings.json, such as "F2" or "Ctrl+Shift+R".</summary>
internal static class HotkeyText
{
    private static readonly KeysConverter Converter = new();

    public static string Format(Keys keys) => Converter.ConvertToInvariantString(keys) ?? "";

    /// <summary>False for unreadable text and for modifier keys alone.</summary>
    public static bool TryParse(string? text, out Keys keys)
    {
        keys = Keys.None;
        if (string.IsNullOrWhiteSpace(text))
            return false;
        try
        {
            if (Converter.ConvertFromInvariantString(text) is not Keys parsed)
                return false;
            var code = parsed & Keys.KeyCode;
            if (code is Keys.None or Keys.ControlKey or Keys.ShiftKey or Keys.Menu or Keys.LWin or Keys.RWin)
                return false;
            keys = parsed;
            return true;
        }
        catch (Exception e) when (e is FormatException or ArgumentException or NotSupportedException)
        {
            return false;
        }
    }
}
```

```csharp
namespace FrameCam.Native;

/// <summary>Global hotkeys (spec 8.5): RegisterHotKey on a hidden message-only window. Actions run on the UI thread.</summary>
internal sealed class HotkeyManager : NativeWindow, IDisposable
{
    private const int WM_HOTKEY = 0x0312;
    private static readonly IntPtr HWND_MESSAGE = new(-3);

    private readonly Dictionary<int, Action> _actions = [];
    private int _nextId = 1;

    public HotkeyManager() => CreateHandle(new CreateParams { Parent = HWND_MESSAGE });

    /// <summary>Registers a key such as Keys.F2 or Keys.Control | Keys.R. False when another program already owns it.</summary>
    public bool Register(Keys keys, Action action)
    {
        uint modifiers = NativeMethods.MOD_NOREPEAT;
        if ((keys & Keys.Alt) != 0) modifiers |= NativeMethods.MOD_ALT;
        if ((keys & Keys.Control) != 0) modifiers |= NativeMethods.MOD_CONTROL;
        if ((keys & Keys.Shift) != 0) modifiers |= NativeMethods.MOD_SHIFT;
        int id = _nextId++;
        if (!NativeMethods.RegisterHotKey(Handle, id, modifiers, (uint)(keys & Keys.KeyCode)))
            return false;
        _actions[id] = action;
        return true;
    }

    public void UnregisterAll()
    {
        foreach (int id in _actions.Keys)
            NativeMethods.UnregisterHotKey(Handle, id);
        _actions.Clear();
    }

    protected override void WndProc(ref Message m)
    {
        if (m.Msg == WM_HOTKEY && _actions.TryGetValue((int)m.WParam, out var action))
            action();
        else
            base.WndProc(ref m);
    }

    public void Dispose()
    {
        UnregisterAll();
        DestroyHandle();
    }
}
```

```csharp
using System.Runtime.InteropServices;
using FrameCam.Core;
using FrameCam.Native;
using FrameCam.Recording;
using Microsoft.Win32;

namespace FrameCam.UI;

/// <summary>
/// The control bar (spec 8.4) and main window: owns the frame, magnifier, recorder, hotkeys and settings.
/// Closing it ends the program, after any recording in progress has been saved.
/// </summary>
internal sealed class ControlBarForm : Form
{
    private readonly string _settingsPath;
    private AppSettings _settings;
    private readonly FrameWindow _frame;
    private readonly MagnifierWindow _magnifier;
    private readonly IScreenRecorder _recorder = new ScreenRecorderLibRecorder();
    private readonly HotkeyManager _hotkeys = new();

    private readonly Button _recordButton = new() { Text = "● 錄影", AutoSize = true };
    private readonly Button _screenshotButton = new() { Text = "截圖", AutoSize = true };
    private readonly Button _sizeButton = new() { Text = "尺寸 ▾", AutoSize = true };
    private readonly Button _pickButton = new() { Text = "選視窗", AutoSize = true };
    private readonly Button _folderButton = new() { Text = "資料夾", AutoSize = true };
    private readonly Button _settingsButton = new() { Text = "設定", AutoSize = true };
    private readonly Label _status = new() { AutoSize = true, MaximumSize = new Size(440, 0), Margin = new Padding(6, 2, 6, 6) };

    private readonly System.Windows.Forms.Timer _elapsedTimer = new() { Interval = 500 };
    private readonly System.Windows.Forms.Timer _flashTimer = new() { Interval = 2000 };
    private string _baseStatus = "";
    private DateTime? _recordingSince;
    private string _recordingNote = "";
    private string _stopNote = "";
    private bool _stopping;
    private bool _closeAfterRecording;
    private bool _recordHotkeyFailed;
    private bool _screenshotHotkeyFailed;

    public ControlBarForm(string settingsPath)
    {
        _settingsPath = settingsPath;
        (_settings, string? settingsError) = SettingsStore.Load(settingsPath);
        var (region, monitor) = RegionPlacement.Restore(_settings.LastRegion, Screens.All());
        _frame = new FrameWindow(region, monitor) { SnapSource = WindowEnumerator.SnapTargetsFor };
        _magnifier = new MagnifierWindow(_frame);
        _frame.ScaleChanged += (_, _) => OnDisplayChanged();

        _recorder.Started += (_, _) => OnRecordingStarted();
        _recorder.Completed += (_, path) => OnRecordingEnded($"{_stopNote}已存檔 {Path.GetFileName(path)}");
        _recorder.Failed += (_, error) => OnRecordingEnded($"錄影失敗：{error}");
        _elapsedTimer.Tick += (_, _) => ShowRecordingTime();
        _flashTimer.Tick += (_, _) =>
        {
            _flashTimer.Stop();
            _status.Text = _baseStatus;
        };

        _recordButton.Click += (_, _) => ToggleRecording();
        _screenshotButton.Click += (_, _) => TakeScreenshot();
        _sizeButton.Click += (_, _) => ShowSizeMenu();
        _pickButton.Click += (_, _) => PickWindow();
        _folderButton.Click += (_, _) => OpenFolder();
        _settingsButton.Click += (_, _) => OpenSettings();

        SuspendLayout();
        AutoScaleDimensions = new SizeF(96F, 96F);
        AutoScaleMode = AutoScaleMode.Dpi;
        Text = "FrameCam";
        FormBorderStyle = FormBorderStyle.FixedToolWindow;
        MaximizeBox = false;
        MinimizeBox = false;
        TopMost = true;
        StartPosition = FormStartPosition.Manual;
        AutoSize = true;
        AutoSizeMode = AutoSizeMode.GrowAndShrink;
        var buttons = new FlowLayoutPanel { AutoSize = true, WrapContents = false };
        buttons.Controls.AddRange(new Control[] { _recordButton, _screenshotButton, _sizeButton, _pickButton, _folderButton, _settingsButton });
        var layout = new FlowLayoutPanel { AutoSize = true, FlowDirection = FlowDirection.TopDown, WrapContents = false };
        layout.Controls.AddRange(new Control[] { buttons, _status });
        Controls.Add(layout);
        ResumeLayout(false);
        PerformLayout();

        if (settingsError is not null)
            SetStatus(settingsError);
    }

    protected override void OnHandleCreated(EventArgs e)
    {
        base.OnHandleCreated(e);
        CaptureExclusion.Apply(Handle);
    }

    protected override void OnLoad(EventArgs e)
    {
        base.OnLoad(e);
        var area = Screen.FromRectangle(_frame.Monitor.Bounds.ToRectangle()).WorkingArea;
        Location = new Point(area.Right - Width - 16, area.Top + 16);
        _frame.Show();
        SystemEvents.DisplaySettingsChanged += OnDisplaySettingsChanged;
        RegisterHotkeys();
    }

    protected override bool ProcessCmdKey(ref Message msg, Keys keyData) =>
        _frame.TryHandleArrow(keyData) || base.ProcessCmdKey(ref msg, keyData);

    protected override void OnFormClosing(FormClosingEventArgs e)
    {
        if (_recorder.IsRecording)
        {
            e.Cancel = true;
            _closeAfterRecording = true;
            if (!_stopping)
                StopRecording("");
            SetStatus("正在存檔，完成後結束…");
            return;
        }
        SaveSettings();
        base.OnFormClosing(e);
    }

    protected override void OnFormClosed(FormClosedEventArgs e)
    {
        SystemEvents.DisplaySettingsChanged -= OnDisplaySettingsChanged;
        _hotkeys.Dispose();
        _recorder.Dispose();
        _elapsedTimer.Dispose();
        _flashTimer.Dispose();
        _magnifier.Dispose();
        _frame.Dispose();
        base.OnFormClosed(e);
    }

    // ---- Recording (spec 8.1, 9) ----

    private void ToggleRecording()
    {
        if (_stopping)
            return; // already finishing the file
        if (_recorder.IsRecording)
        {
            StopRecording("");
            return;
        }
        if (OutputDirectory.EnsureWritable(_settings.OutputFolder) is { } folderError)
        {
            SetStatus(folderError);
            return;
        }
        string path = FileNamer.NextPath(_settings.OutputFolder, DateTime.Now, ".mp4", File.Exists);
        var monitor = _frame.Monitor;
        bool hasAudio;
        try
        {
            hasAudio = _recorder.Start(new RecordingRequest(monitor.DeviceName, monitor.Bounds, _frame.CaptureRegion, _settings.FramesPerSecond, path));
        }
        catch (Exception ex)
        {
            SetStatus($"無法開始錄影：{ex.Message}");
            return;
        }
        _recordingNote = hasAudio ? "" : "（找不到播放裝置，只錄畫面）";
        _stopNote = "";
        _frame.Locked = true;
        _recordButton.Text = "■ 停止";
        _sizeButton.Enabled = _pickButton.Enabled = false;
        SetStatus("準備錄影…" + _recordingNote);
    }

    private void StopRecording(string note)
    {
        _stopping = true;
        _stopNote = note;
        _recordButton.Enabled = false;
        _elapsedTimer.Stop();
        SetStatus(note + "正在存檔…");
        _recorder.Stop();
    }

    private void OnRecordingStarted()
    {
        if (_stopping)
            return;
        _recordingSince = DateTime.Now;
        _elapsedTimer.Start();
        ShowRecordingTime();
    }

    private void ShowRecordingTime()
    {
        if (_recordingSince is { } since)
            SetStatus($"● 錄影中 {DateTime.Now - since:hh\\:mm\\:ss}{_recordingNote}");
    }

    private void OnRecordingEnded(string message)
    {
        _elapsedTimer.Stop();
        _recordingSince = null;
        _stopping = false;
        _frame.Locked = false;
        _recordButton.Text = "● 錄影";
        _recordButton.Enabled = true;
        _sizeButton.Enabled = _pickButton.Enabled = true;
        SetStatus(message);
        if (_closeAfterRecording)
            Close();
    }

    // ---- Screenshot (spec 8.2) ----

    private void TakeScreenshot()
    {
        if (OutputDirectory.EnsureWritable(_settings.OutputFolder) is { } folderError)
        {
            SetStatus(folderError);
            return;
        }
        string path = FileNamer.NextPath(_settings.OutputFolder, DateTime.Now, ".png", File.Exists);
        try
        {
            ScreenshotTaker.Save(_frame.CaptureRegion, path);
            FlashStatus($"已存 {Path.GetFileName(path)}");
        }
        catch (Exception ex) when (ex is ExternalException or IOException or UnauthorizedAccessException)
        {
            SetStatus($"截圖存檔失敗：{ex.Message}");
        }
    }

    // ---- Region tools (spec 7.5) ----

    private void ShowSizeMenu()
    {
        var menu = new ContextMenuStrip();
        var monitor = _frame.Monitor;
        foreach (var size in FrameAdjust.Presets)
        {
            var target = FrameAdjust.ApplyPreset(_frame.CaptureRegion, size, monitor.Bounds);
            var item = new ToolStripMenuItem($"{size.Width} × {size.Height}") { Enabled = target is not null };
            if (target is { } region)
                item.Click += (_, _) => _frame.SetRegion(region, monitor);
            menu.Items.Add(item);
        }
        var full = new ToolStripMenuItem("整個螢幕");
        full.Click += (_, _) => _frame.SetRegion(FrameAdjust.FullMonitor(monitor.Bounds), monitor);
        menu.Items.Add(full);
        menu.Closed += (_, _) => BeginInvoke(menu.Dispose); // after the item's Click has run
        menu.Show(_sizeButton, new Point(0, _sizeButton.Height));
    }

    private void PickWindow()
    {
        using var picker = new WindowPicker();
        if (picker.ShowDialog(this) != DialogResult.OK || picker.Picked is not { } window)
            return;
        var monitor = Screens.At(picker.PickedAt);
        if (FrameAdjust.FitToWindow(window, monitor.Bounds) is { } region)
            _frame.SetRegion(region, monitor);
        else
            FlashStatus($"這個視窗太小，至少要 {FrameGeometry.MinSize}×{FrameGeometry.MinSize}");
    }

    private void OpenFolder()
    {
        if (OutputDirectory.EnsureWritable(_settings.OutputFolder) is { } folderError)
        {
            SetStatus(folderError);
            return;
        }
        Process.Start(new ProcessStartInfo(_settings.OutputFolder) { UseShellExecute = true });
    }

    // ---- Settings and hotkeys (spec 8.5) ----

    private void OpenSettings()
    {
        using var dialog = new SettingsForm(_settings, _recordHotkeyFailed, _screenshotHotkeyFailed);
        if (dialog.ShowDialog(this) != DialogResult.OK)
            return;
        _settings = dialog.ToSettings(_settings);
        SaveSettings();
        RegisterHotkeys();
    }

    private void RegisterHotkeys()
    {
        _hotkeys.UnregisterAll();
        _recordHotkeyFailed = !TryRegister(_settings.RecordHotkey, ToggleRecording);
        _screenshotHotkeyFailed = !TryRegister(_settings.ScreenshotHotkey, TakeScreenshot);
        var failed = new List<string>();
        if (_recordHotkeyFailed)
            failed.Add($"錄影 {_settings.RecordHotkey}");
        if (_screenshotHotkeyFailed)
            failed.Add($"截圖 {_settings.ScreenshotHotkey}");
        if (failed.Count > 0)
            SetStatus($"快捷鍵登記失敗，可能已經被其他程式使用：{string.Join("、", failed)}。用按鈕還是可以錄影和截圖。");
    }

    private bool TryRegister(string text, Action action) =>
        HotkeyText.TryParse(text, out var keys) && _hotkeys.Register(keys, action);

    private void SaveSettings()
    {
        var r = _frame.CaptureRegion;
        _settings = _settings with { LastRegion = new SavedRegion(_frame.Monitor.DeviceName, r.Left, r.Top, r.Width, r.Height) };
        try
        {
            SettingsStore.Save(_settingsPath, _settings);
        }
        catch (Exception ex) when (ex is IOException or UnauthorizedAccessException)
        {
            SetStatus($"設定存檔失敗：{ex.Message}");
        }
    }

    // ---- Monitor changes (spec 9) ----

    private void OnDisplaySettingsChanged(object? sender, EventArgs e) => BeginInvoke(OnDisplayChanged);

    private void OnDisplayChanged()
    {
        if (_recorder.IsRecording && !_stopping)
            StopRecording("螢幕設定改變，已停止錄影並");
        var r = _frame.CaptureRegion;
        var (region, monitor) = RegionPlacement.Restore(
            new SavedRegion(_frame.Monitor.DeviceName, r.Left, r.Top, r.Width, r.Height), Screens.All());
        _frame.SetRegion(region, monitor);
    }

    // ---- Status line ----

    /// <summary>Shows a message that stays until the next one.</summary>
    private void SetStatus(string text)
    {
        _baseStatus = text;
        if (!_flashTimer.Enabled)
            _status.Text = text;
    }

    /// <summary>Shows a message for 2 seconds, then the previous one again.</summary>
    private void FlashStatus(string text)
    {
        _status.Text = text;
        _flashTimer.Stop();
        _flashTimer.Start();
    }
}
```

```markdown
# FrameCam

類似 oCam 的 Windows 螢幕錄影工具。拖曳錄影框時有放大鏡，可以把框對到指定的像素。

- 框選範圍錄成 MP4（最高每秒 60 格），同時錄系統聲音
- 用同一個框截圖存成 PNG
- 方向鍵一次移 1 像素，Ctrl+方向鍵調整最後拖過的那條邊
- 常用尺寸、自動對齊視窗邊緣、選視窗
- 快捷鍵：F2 錄影／停止、F3 截圖（可以在設定裡改）

設計文件：`docs/superpowers/specs/2026-10-14-framecam-design.md`

## 需要

- Windows 10 2004 版以後，或 Windows 11（x64）
- .NET 10 SDK
- Visual C++ 可轉散發套件 x64（ScreenRecorderLib 需要）

## 執行

    dotnet run --project src/FrameCam

影片和截圖預設存在「影片\FrameCam」，設定檔在 `%APPDATA%\FrameCam\settings.json`。

## 測試

    dotnet test tests/FrameCam.Core.Tests
    dotnet test tests/FrameCam.CaptureTests

`FrameCam.CaptureTests` 會在螢幕上開視窗、播放聲音約 30 秒，執行時不要動滑鼠和鍵盤。錄影相關的測試需要 PATH 裡有 `ffmpeg` 和 `ffprobe`，找不到時會略過。
```
